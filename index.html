💻 Example Code - Two Pointer Technique

// Two Sum Problem - Sorted Array
function twoSum(arr, target) {
    let left = 0;
    let right = arr.length - 1;
    
    while (left < right) {
        let sum = arr[left] + arr[right];
        
        if (sum === target) {
            return [left, right];
        } else if (sum < target) {
            left++;
        } else {
            right--;
        }
    }
    return [-1, -1];
}

// Example
let arr = [1, 2, 3, 4, 6];
let target = 6;
console.log(twoSum(arr, target)); // Output: [1, 3]

💻 Pehla ML Model - Linear Regression

# Python Code - House Price Prediction
import numpy as np
from sklearn.linear_model import LinearRegression

# Data: [Area in sq ft]
X = np.array([[600], [800], [1000], [1200], [1500]])

# Prices in lakhs
y = np.array([30, 40, 50, 60, 75])

# Model banao
model = LinearRegression()
model.fit(X, y)

# Prediction karo
new_house = [[1100]]
predicted_price = model.predict(new_house)

print(f"1100 sq ft ka ghar: ₹{predicted_price[0]:.2f} lakh")
# Output: 1100 sq ft ka ghar: ₹55.00 lakh

🔥 Problem of the Day

Two Sum Problem

Difficulty: Easy

Problem: Ek array diya gaya hai aur ek target number. Aapko do numbers dhundne hain jinki sum target ke barabar ho.

Example:

Input: arr = [2, 7, 11, 15], target = 9
Output: [0, 1]
Explanation: arr[0] + arr[1] = 2 + 7 = 9

Hint: HashMap use karo for O(n) solution!
